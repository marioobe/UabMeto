# Uji Coba APK di SMP Putri Kefamenanu

Status: **siap uji terbatas** (2 siswa kelas IX, satu kelas).
Tanggal: **Senin 16 November 2026** (pretes + perlakuan) dan
**Kamis 19 November 2026** (postes tunda 3 hari).
Lokasi: SMP Putri Kefamenanu, dua ruang terpisah untuk tes lisan.

Dokumen ini adalah SOP pelaksanaan. Instrumen cetak ada di berkas
`03`–`07`; checklist perangkat ada di `11-checklist-apk.md`. Nama guru
sengaja dikosongkan dan diisi saat tim tiba di sekolah.

## 1. Tujuan dan batas

Uji ini mengukur **perubahan pengenalan kosakata Bahasa Dawan** setelah
siswa memakai APK selama satu sesi, lalu mengukur retensinya setelah
3 hari. Uji ini juga mengumpulkan penilaian siswa dan guru tentang
keterbacaan serta kelayakan aplikasi.

Batas yang harus dicatat di laporan:

- Hanya **2 siswa**; ini studi kasus awal, bukan uji efektivitas skala luas.
- Tidak ada kelompok kontrol.
- Postes dilakukan **3 hari** setelah perlakuan, tanpa postes langsung.
- APK hanya berisi 3 pelajaran Topik 1; tes hanya memakai kosakata dari
  ketiga pelajaran itu.
- Tidak ada audio. Tes mengukur **arti dan bentuk tulis kosakata**, bukan
  pelafalan, mendengar, atau berbicara.
- Sekolah tidak memiliki pembelajaran Bahasa Dawan, sehingga pretes
  menjadi baseline dan APK menjadi satu-satunya paparan terstruktur.
- Tes tidak melalui peninjauan ahli tambahan karena Ibu Nofri tidak dapat
  memeriksa. Semua butir diambil langsung dari kosakata yang sudah
  divalidasi, tetapi instrumen tes tidak diklaim "validasi ahli".
- Izin diletakkan di tingkat guru dan mewakili siswa. Persetujuan orang
  tua tidak diminta; ini dicatat sebagai batasan, bukan sebagai prosedur
  ideal.

## 5. Perlengkapan

- APK ARM64 0.5.0 dan APK universal cadangan di flashdisk/Drive.
- Kabel USB, charger, power bank, dan adaptor.
- 2 set pretes, 2 set postes, 2 set kuesioner siswa, 1 set kuesioner guru.
- 2 lembar kartu kata (satu per ruang), 2 lembar skor penguji per siswa.
- Timer/stopwatch, pulpen, papan jalan, dan map.
- Surat izin guru, lembar kesediaan siswa, dan template rekap.
- Laptop untuk input data setelah sesi (Google Form/Sheet).
- Air minum dan tisu (opsional).

Cetak semua instrumen dalam **A4 hitam-putih**. Cetak satu set cadangan.
Halaman **kartu kata** (`03` dan `04`) dicetak terpisah dari lembar skor,
lalu dilipat atau dimasukkan ke map berbeda: kartu dipegang penguji, lembar
skor tidak boleh terlihat siswa. Jangan mencetak kartu dan skor pada sisi
kertas yang sama.

Tanda tangan kepala sekolah pada surat izin bersifat **opsional**. Jika
kepala sekolah tidak ada di tempat, izin guru sudah cukup untuk kegiatan;
tulis catatan "kepala sekolah tidak di tempat" di surat.

## 6. Persiapan perangkat

1. Bersihkan data lama OPPO. `adb shell pm clear` **ditolak** ColorOS
   (`SecurityException: CLEAR_APP_USER_DATA`), jadi pakai uninstall lalu
   pasang ulang:
   `adb uninstall id.uabmeto.app` → `adb install -r <apk>`.
   Alternatif manual: Pengaturan → Aplikasi → Uab Meto → Uninstall.
   Uninstall menghapus nickname dan progres, jadi lakukan **sebelum**
   mengisi kode `P01`.
2. Pasang APK di HP siswa. Jika ARM64, pakai APK 0.5.0; jika 32-bit,
   pakai APK universal cadangan. Catat model, versi Android, dan ABI.
   APK universal yang sudah diuji: `Builds/Android/uabmeto-sekolah-universal.apk`
   (44.293.568 byte, SHA-256 `D94FF98A…22D3`), lihat `11-checklist-apk.md`.
3. Buka aplikasi di kedua HP, isi kode `P01` dan `P02`, lalu tutup.
4. Set skala font sistem ke **1.0×**, timeout layar 5–10 menit,
   orientasi portrait, dan baterai minimal 80%.
5. Matikan Wi-Fi dan data seluler saat sesi belajar. Banner
   "Offline — pembelajaran tetap bisa dilanjutkan" adalah normal.
6. Jelaskan bahwa hanya tab **Beranda** dan pelajaran yang dipakai;
   Tutor AI dan Peringkat tidak aktif tanpa server.
7. Uji membuka Pelajaran 1 lalu kembali. Jangan menyelesaikan pelajaran
   saat uji coba, atau hapus data lagi sebelum sesi.

## 7. Alur tes lisan

- Pretes dan postes memakai 20 butir yang sama; urutan postes diacak.
- Penguji A dan B membacakan naskah yang sama. Kalibrasi 15 menit
  dilakukan sebelum Senin (lihat `05-kunci-dan-rubrik.md`).
- Bagian A: penguji menunjukkan kartu kata Dawan; siswa menjawab arti
  dalam Bahasa Indonesia. Penguji **tidak** menilai pelafalan Dawan.
- Bagian B: penguji menyebut kata Indonesia; siswa menjawab bentuk
  Dawan secara lisan. Jika jawaban lisan sulit dipahami, minta siswa
  menuliskannya; jangan menilai ejaan secara ketat.
- Tidak ada petunjuk, tidak ada umpan balik benar/salah, dan tidak ada
  pengulangan yang memberi jawaban. Boleh mengulang pertanyaan sekali.
- Skor 1 untuk jawaban benar, 0 untuk salah/tidak tahu. Maksimum 20.
- Siswa `P01` dan `P02` berada di ruang terpisah agar tidak saling
  mendengar.

## 8. Perlakuan APK

- Siswa membuka Beranda, menekan "Mulai/Lanjutkan", dan menyelesaikan
  tiga pelajaran Topik 1 secara berurutan.
- Penguji mendampingi tetapi **tidak menjawab soal** untuk siswa.
- Jika siswa bertanya arti kata, penguji mengarahkan ke kartu kosakata
  di aplikasi, bukan memberi jawaban langsung.
- Catat pelajaran yang selesai, waktu mulai/selesai, dan bantuan yang
  diberikan.
- Jika siswa selesai lebih awal, boleh mengulang pelajaran sebagai
  latihan; replay tidak menambah XP.
- Jangan mengubah pengaturan atau membuka tab lain selama sesi.

## 9. Kuesioner

- Kuesioner siswa diisi setelah sesi APK, di kertas, tanpa nama.
- Kuesioner guru diisi oleh guru pendamping; nama dikosongkan dan
  diisi sendiri.
- Google Form hanya dipakai untuk merekap data setelah tim pulang,
  bukan untuk pengisian siswa di sekolah.

## 10. Data dan etika

- Gunakan hanya kode `P01`/`P02`; jangan menulis nama siswa di lembar
  mana pun.
- Jangan merekam audio/video siswa.
- Simpan lembar kertas di map tertutup; masukkan ke spreadsheet setelah
  sesi; hapus foto/scan jika tidak diperlukan.
- Data dilaporkan secara agregat dan anonim. Kutipan terbuka tidak boleh
  memuat identitas.
- Setelah postes, hapus data aplikasi di kedua HP dan uninstall jika
  sekolah tidak memerlukannya.
