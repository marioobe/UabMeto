## 7. Risiko

1. **Konten tervalidasi masih nol.** Beranda F1 akan menampilkan state
   kosong. Itu benar, bukan bug.
2. **Font belum diuji.** Glif `ā`, `’`, `ʔ` bisa hilang.
3. **Landscape tanpa mockup.** Spesifikasi turunan bisa keliru.
4. **TalkBack.** Unity tidak memetakan otomatis; jangan klaim aksesibel
   sebelum diuji.
5. **Ukuran APK.** Font ikon dan font teks menambah ukuran; target 150 MB
   belum terancam, tetapi harus diukur.

## 8. Tindakan berikutnya

1. Setujui laporan ini.
2. Mulai F1: tema, font, prefab, shell, Beranda, satu pelajaran.
3. Siapkan konten `validated` minimal satu pelajaran agar F1 bisa diuji
   dengan data nyata.
