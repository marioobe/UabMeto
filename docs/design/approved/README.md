# Referensi Visual yang Disetujui

Status: **arah visual disetujui; konten di dalam gambar tidak disetujui.**

Berkas di folder ini adalah tangkapan layar dari paket Stitch
`stitch_uab_meto_design_system.zip` (diterima 2026-10-26). Fungsinya hanya
sebagai acuan komposisi, warna, dan hierarki saat membangun UI Unity.

## Yang disetujui

- Palet indigo malam, krem, kuning tenun, terakota.
- Tipografi Plus Jakarta Sans untuk judul dan Inter untuk isi.
- Motif belah ketupat sebagai garis aksen.
- Susunan kartu, bilah progres, chip, dan navigasi empat tab.
- Panel umpan balik, banner offline, dan state "belum dapat dinilai".

## Yang tidak disetujui

Gambar-gambar ini **memuat teks Dawan yang belum tervalidasi**, klaim dan
angka karangan, serta atribusi nama penutur. Jangan menyalin teks dari
gambar ke kode.

Rincian temuan ada di `../design-review-stitch.md`. Aturan konten ada di
`../content-binding.md`.
